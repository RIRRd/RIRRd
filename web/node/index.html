ONE APPLICATION / TWO COMPLEMENTARY CHECKS

Integrated RPKI

Checking capability

RIRRd is being developed to collect RPKI repositories, validate their certificate chains and signed objects, and serve validated payloads to routers over RTR. IRR queries and RPKI origin validation will share one application lifecycle.

Independent RPKI validation and RTR availability are reported from the running service. A downloaded ROA JSON file alone is not an independent validator.

Origin checks are enabled only when a usable validated dataset is available.

Routinator is already Rust software. RIRRd uses an attributed, pinned upstream validation engine inside its own binary; it does not claim to have invented or independently reimplemented that engine. Live IRR suppression and full integrated qualification remain separate work.
