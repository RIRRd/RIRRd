# RIRRd 0.1.0-beta.2

Public beta under the dedicated [RIRRd organization](https://github.com/RIRRd).
The canonical source and issue tracker are [RIRRd/RIRRd](https://github.com/RIRRd/RIRRd).
Project code is MIT licensed. Human and AI-assisted contributions are welcome
with review, reproducible tests and clear provenance.

This release follows the private beta checkpoint with compact IPv4/IPv6 ROV
indexes, bounded origin-validation explanations, responsive query tools and a
repeatable verification suite. It combines the independently self-hostable IRR
service and an optional attributed Routinator/rpki-rs validator in one Rust
process. The community network at irrd.tools is a separate deployment.

Build verification covers locked Rust tests on Linux x86-64, Linux ARM64 and
Windows, 56 independent protocol/recovery contracts, isolated website workflows,
source coverage with an enforced 92% floor, audits, short fuzzing and Docker
smoke checks. Tagged beta publication waits for the shared CI suite and native
DEB/RPM package checks. Published run URLs and exact revisions are evidence;
a version number alone does not establish a passing release build.

Full IRRd parity, authentication/account workflows, complete mirroring
interoperability, live policy suppression and production qualification remain
incomplete. Current RPKI collection is RRDP-only and can reject publication
points. This release is for evaluation and read-only tests; review generated
router policy before applying it. See [beta status](../BETA_STATUS.md).

The original project's Git history and historical beta tag are preserved.
Historical Actions URLs refer to their original repository; current automation
and releases run in RIRRd/RIRRd. No database format change is introduced by the
organization/publication update.
