Source coverage

No source coverage result has been published yet.

Line coverage measures execution, not correctness or full feature parity. This profile includes test modules within Rust source files; external fixture, harness and dependency files are excluded.

Configured for each push and pull request

  • Formatting, strict Clippy and locked Rust tests on Linux x86-64, Linux ARM64 and Windows.
  • Independent TCP, HTTP and GraphQL contracts, malformed inputs, source isolation, redaction, restart and backup recovery.
  • Both websites in a real browser, backed by a private synthetic registry and a separate submission queue.
  • Source coverage with native and external tests, dependency auditing, source hygiene and short RPSL/NRTMv3 fuzz runs.
  • Container deployment smoke checks. Pinned IRRd comparison, router tools and native packages have additional dedicated workflows.

Workflow configuration and recorded execution are listed separately. GitHub run status has not been verified for this local snapshot. Open the public CI workflow to inspect current runs.

Reproduce a build check

python3 tools/testing/run.py --profile core --out /tmp/rirrd-checks
python3 tools/testing/run.py --profile web --out /tmp/rirrd-web-checks
bash tools/testing/coverage.sh /tmp/rirrd-coverage

Rust and Python are required. Browser checks also need Chromium or Chrome and the distribution’s Python Markdown package. Coverage uses the pinned cargo-llvm-cov version documented in the repository.
